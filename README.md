# README TEMPORARIO

## Passos para executar o projeto

1 - Clonar o Repositorio

2 - Executar os comandos:

```
npm install -g nodemon
```

```
npm install
```

Caso queira mexer no frontend:

```
cd frontend/
npm install
```

3 - configuracao do banco de dados

Voce deve ter o mysql ou mariadb instalado na maquina, então:

```
cp .env.example .env
```

dentro da usa .env criada, preencha com os seus dados.

4 - Divirta-se !
